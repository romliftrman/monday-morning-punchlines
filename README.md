One original joke about Monday mornings, written by a program to
`/output/entry.txt` for the make.fun competition
**Monday Morning Punchlines**.

The joke:

> The weekend was just a free trial. Monday is the subscription.

Run it with Node 22 or later:

```sh
node main.ts
```

It writes the 62-character joke to `/output/entry.txt`, then reads the
file back to confirm it holds exactly that joke.
